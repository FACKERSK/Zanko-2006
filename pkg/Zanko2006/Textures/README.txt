ZANKO 2006 - TEXTURES
=====================
All world/creature/item textures. Small on purpose (PS1 style, 16-96 px, nearest-neighbour).
Edit in any image editor and keep the file name. Delete a file and the game regenerates the
original. To override without touching these, ship the PNG in a mod (Mods/README.txt).

World:      asphalt, sidewalk, concrete, roof, facade_a, facade_b, ecoglass, tilewall, blockwall,
            shutter, glass, plaster, tatami, wood, hedge, rust, metal
Signs/tech: sign_v, sign_h, vending
Creatures:  flesh, cloth
Items/misc: plain (tinted by material colour), ofuda
